// why this order

React vs Azure — decided by hireability

After Phase 2 (ASP.NET Core + EF Core) you're already backend-hireable. Phases 3–4 exist to maximize how hireable the finished project looks, in the time that's left.

Phase 3 → React (minimal)

Just enough to be legitimately "fullstack" in an interview — not a polished frontend. No deep testing, no component library unless time remains.

Phase 4 → Deploy + Apply

A live URL beats any resume bullet. Applications start mid-phase, not after it ends.
